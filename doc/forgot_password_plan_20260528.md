# 忘记密码功能实现计划 (手机号验证)

## 1. 任务背景
目前系统支持用户名密码登录和注册，但在用户遗忘密码时缺乏找回手段。为了提升用户体验和安全性，计划增加基于手机号短信验证码的密码找回功能。

## 2. 技术方案

### 2.1 后端实现
- **验证码管理**: 
    - 使用 Redis 存储验证码，Key 格式为 `sms:code:{phone}`。
    - 验证码长度 6 位数字，有效期 5 分钟。
    - 增加频率限制（如 1 分钟内只能发送一次）。
- **接口设计**:
    1. `POST /api/auth/send-code`: 发送验证码。验证手机号是否已注册。
    2. `POST /api/auth/reset-password`: 重置密码。校验手机号、验证码，更新数据库。
- **服务类**:
    - `VerificationCodeService`: 处理 Redis 相关逻辑。
    - `SmsService`: 短信发送接口（初期实现为 Mock，日志打印）。
    - `AuthService`: 增加重置密码业务逻辑。

### 2.2 前端实现
- **登录页增强**: 增加“忘记密码”入口。
- **重置密码表单**:
    - 手机号输入框（正则校验）。
    - 验证码输入框 + 获取验证码按钮（带 60s 倒计时）。
    - 新密码输入框 + 确认密码。
- **交互逻辑**: 成功重置后自动跳转登录页，并给予提示。

## 3. 实施步骤

### 第一阶段：后端基础开发
1. 添加 Redis 依赖（已存在）。
2. 实现 `VerificationCodeService` 及其配置。
3. 实现 `SmsService` (Mock版)。
4. 在 `AuthService` 中添加 `sendResetCode` 和 `resetPassword` 方法。
5. 在 `AuthController` 中暴露相应接口。

### 第二阶段：前端界面开发
1. 在 `auth.js` 中封装新接口。
2. 修改 `Login.vue` 增加找回密码入口。
3. 实现找回密码的 UI 弹窗或独立页面。
4. 编写前端校验及倒计时逻辑。

### 第三阶段：测试与验证
1. 单元测试后端重置逻辑。
2. 集成测试前端发送验证码 -> 查收日志 -> 输入验证码 -> 重置成功流程。
